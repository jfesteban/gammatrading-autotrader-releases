# Gamma Trading AutoTrader — downloads

Installers for the **Gamma Trading AutoTrader** (Mac and Windows). This page holds only the
installers; there is no source code here.

**Download:** open [the latest release](https://github.com/jfesteban/gammatrading-autotrader-releases/releases/latest)
and pick the file for your computer:

| Computer | File |
|---|---|
| Mac (Apple chip) | `Gamma-Trading-AutoTrader-<version>.dmg` |
| Windows 10 / 11 | `Gamma-Trading-AutoTrader-<version>-Setup.exe` |

From version 0.5.7 on, the app finds new versions by itself: a banner appears in the app, and
**Install update** downloads and installs it with one click. Every release is signed: the app
refuses any file whose signature does not match.

Setup guides, help and your account: [gamma-trading.com](https://gamma-trading.com).
